# Jyotirmoy Konwar — Portfolio

Source for my personal site, <https://jyotirmoykonwar.github.io>, built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme.

- To edit content (bio, CV, projects, publications, resume PDF), see [HOW_TO_UPDATE.md](HOW_TO_UPDATE.md).
- To preview locally: `docker compose up`, then open <http://localhost:8080>.
