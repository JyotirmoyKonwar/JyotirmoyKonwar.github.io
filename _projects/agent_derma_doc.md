Deployed a **multimodal medical agent on Hugging Face Spaces**, combining a fine-tuned **Swin Transformer** for skin disease classification with a Gradio interface.

- Fine-tuned **Qwen-2.5-1.5B** using Unsloth.
- LangChain-driven RAG pipeline over Pinecone vector stores for context-aware medical QA.

### Tech Stack

- Python, Hugging Face, PyTorch, Transformers, LangChain, LangGraph, Pinecone, Unsloth, Gradio
