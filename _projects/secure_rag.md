Engineered an enterprise **RAG pipeline** using **LLaMA 3** and **ChromaDB**, enforcing granular **Role-Based Access Control (RBAC)** via metadata filtering for strict multi-tenant data isolation.

- High-throughput **FastAPI** microservices integrated with a **Streamlit** frontend and stateful session management.
- Local inference via **Ollama** and **SentenceTransformers** to keep data private.

### Tech Stack

- Python, LLaMA 3, ChromaDB, FastAPI, Streamlit, Ollama, SentenceTransformers
